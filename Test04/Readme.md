# Supervised Machine Learning Regression Project

## Problem Statement
Predict the sales of grocery items using Blinkit dataset.

## Dataset
Blinkit Grocery Sales Dataset

Target Variable:
Sales

## Data Preprocessing
- Handling missing values
- Fixing data types
- Removing duplicates
- Handling categorical variables
- Feature scaling
- Removing irrelevant features
- Train-test split
- Outlier detection

## Algorithms Used
1. Linear Regression
2. Decision Tree Regressor
3. Random Forest Regressor

## Evaluation Metrics
- R2 Score
- MSE
- RMSE
- MAE

## Conclusion
Random Forest model achieved better performance compared to Linear Regression and Decision Tree.
